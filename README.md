# Cheek Bite

A fluffy orange kitten in a blue bow playfully bites the cheek of a chubby baby penguin wearing a red scarf in a snowy golden-hour scene. The AI-generated image is held in this repository as `picture.jpg`.

## How it works

`main.py` copies the held image to the output path as `entry.png`. The grader accepts JPEG bytes under the name `entry.png`.

## Run locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
